dsh-dev-reloader 架构图

DSH 开发热重载插件 · 三进程边界 / IPC 信任 / 变更分类 / 状态机 / 重启序列

01总览：三进程边界

HOSTDSH 宿主进程（Cordis）

  • src/index.ts — 插件入口 + installSettingsSection 设置项
  • src/bridge/activity.ts — 订阅 ctx.agents/jobs，生成 ActivitySnapshot
  • src/bridge/client.ts — 认证 IPC 客户端
  • src/bridge/routes.ts — /plugins/dsh-dev-reloader/{status,health,command}（仅 loopback）
  • src/bridge/spawn.ts — detached 拉起 supervisor

SUPERVISOR独立 Node supervisor

  • lib/supervisor/cli.js --serve --profile <profile> 常驻
  • 锁 + 私有 token + Unix socket IPC（HMAC 挑战应答，token 永不上线）
  • 发现 / 分类 / 监听 / 构建 / 门控 / 健康检查 / 生命周期 / 状态机
  • 一次性认证 self-handoff（handoff.ts）

CLIENT浏览器客户端（web bundle）

  • lib/client.js — 设置卡片 SettingsCard.tsx
  • reconnect.ts — 一次性恢复（sessionStorage 标记 + 轮询 + 单次 reload）
  • api.ts — 同源路由调用（status / health / command）
  • 注入 slots / locale / settingsScope / connection / remote

06完整重启序列（动态图）

sequenceDiagram
  autonumber
  participant FS as 项目文件系统
  participant S as Supervisor
  participant G as 活动门控
  participant L as Lifecycle
  participant H as 新 DSH 宿主
  participant B as 浏览器

  FS->>S: 源码变更
  S->>S: 分类 + 构建 (结构化 argv)

  alt full-restart
    S->>G: requestRestart
    G-->>S: 活动空闲 → 放行
    S->>L: restart(host, expectedBootId)
    L->>L: SIGTERM → SIGKILL 兜底 → 端口释放
    L->>H: detached 替换宿主 (注入 DSH_DEV_BOOT_ID)
    L->>L: 健康检查 (HTTP 2xx + bridge bootId)
    H->>S: 新 bridge hello (新 pid/bootId)
    S->>S: prepareBridge → 代际重置
    S->>S: host-started → recovered → watching
    S->>B: 状态广播
    B->>B: 轮询 /health (no-store)
    B->>B: 新 bootId → location.reload() 一次
  else server-hmr
    S->>H: 等待显式 hmr/reload ack
    H-->>S: 匹配 entries → hmr-complete
    S-->>S: 超时 → 升级 full-restart
  else client-hmr
    S->>S: ensurePersistent(dev:web)
  end

07安全与信任边界

领域机制
目录 / 文件权限stateDir 0700；token / 锁 / socket 0600；用户属主校验；O_NOFOLLOW + inode 快照防符号链接攻击
IPC 认证HMAC-SHA256 挑战应答（createProof），token 永不经过线路；nonce 绑定 + 重放检查；peer 代际（pid+bootId）准入，事件与命令都过滤
HTTP 路由仅 loopback（127.0.0.1 / ::1），拒绝 forwarded、跨源、非 JSON；body ≤ 64 KiB；status/health 只返回脱敏公开数据（永不返回 env/token）
命令执行仅 executable + argv，不拼接不可信命令；默认 shell:false，Windows 仅对受信 pnpm shim 使用系统命令包装；输出 bounded + 敏感赋值脱敏；持久进程可 stopAll
失败关闭gate 在 bridge-unknown 时 fail-closed；unexpected-exit 双触发去重；崩溃熔断 bounded；handoff 模糊所有权 fail-closed
恢复浏览器一次性恢复（marker + no-store 轮询 + 新 bootId 才 reload），不会重复刷新
